# 项目约定

> 本文件由 DSH 在会话开始时自动加载，是给 AI 编码助手的项目级指令。
> 更具体的指令优先于更宽泛的指令；本文件不覆盖系统、开发者或用户的直接指令。

## 一、待学习清单（重要，请始终执行）

项目根目录的 **`Need_to_learn.md`** 记录着「本项目用到、或暂时跳过，但用户以后要自己补上」的技术点。

1. 每当出现「先用现成方案、以后再手写」「暂时绕过、以后要搞懂」的决策，**主动往 `Need_to_learn.md` 追加一条**，
   写清「背景」「要掌握的知识点」「提醒时机」。
2. 在合适时机（该模块告一段落、或项目进入工程化收尾 M9 时）**主动提醒用户回来学这一条**。
3. **不要把这类事项只留在对话里** —— 对话会被压缩，文件才是可靠记忆。

## 二、协作方式

- 用户正在**边做边学**：项目要**由他自己写代码**。AI 的职责是**规划、评审、答疑、指出错误**，
  不要替他大段实现功能，也不要在他没问的时候批量改代码。
- 回答用**中文**。
- 讲清「为什么」而不只是「改成什么」：报错要说清根因，方案要说清取舍。

## 三、技术背景

- 技术栈：Spring Boot **4.0.8** + MyBatis（`mybatis-spring-boot-starter:4.0.1`）+ MySQL **8.0.46** + Maven；
  前端先用原生 HTML/CSS/JS，后期换 Vue3。
- 数据库 `web_study`，账号 `root/123456`，Windows 服务名 `MySQL80`。
- **Maven 本地仓库在工作区之外，AI 无法代跑 `mvn`** —— 需要编译、启动或装依赖时，请让用户在 IDEA 中执行。
- 项目主线是「**练 → 测 → 评 → 推**」闭环：做题 → 记录每题对错 → 按知识点聚合 → 算掌握度 → 推荐薄弱点 + 按遗忘曲线推复习。
- 里程碑：M0 环境 → M1 骨架 → M2 用户 → M3 内容管理 → M4 练习闭环 → M5 前端 → M6 计划统计 → M7 智能推荐 → M8 AI 增强 → M9 工程化。

## 四、代码约定

- 包根：`com.wanna.webmanagement`。
- 接口统一前缀 `/api`，返回体 `{code, message, data}`。
- 依赖严格单向：Controller → Service → Mapper；**事务边界放在 Service**。
- 业务异常抛 `BusinessException`，由 `GlobalExceptionHandler`（`@RestControllerAdvice`）统一处理。
